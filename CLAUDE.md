# Working in this repository

## Never name real people or their sites in anything published to GitHub

This repository is public. Commit messages, pull request titles, pull request
bodies, PR comments, issues, and code comments must not name real people or
link to their personal sites.

This applies even when a real site is the design reference being copied, and
even when the name is a well-known public figure or a widely used convention
named after someone.

Instead, describe the thing itself:

- "match the layout from the reference screenshots"
- "a standard academic publication layout"
- "the two-column sticky sidebar pattern"

Not:

- "like <person>'s site"
- "the <person>-style layout"
- "copying <site>.github.io"

Collaborators and co-authors who appear in the site's own content — the
bibliography, project descriptions, advisors in the bio — are fine. Those are
the site's subject matter. The rule is about commentary _about_ the work.

Before opening or editing a PR, re-read the title and body and strip any
personal names that are not part of the site's own content.
